POKEMON FETTUCCINE VERSION - PLAYTEST 13
========================================

Thanks for testing! This is a small build: Solar Blade is now a
one-turn move.


HOW TO PLAY
-----------
1. You need a clean US Pokemon Emerald ROM (not included).
   It should match:
     CRC32: 1F1C08FB
     SHA-1: f3ae088181bf583e55daf962a92bb46f4f1d07b7
2. Apply fettuccine-playtest-13.bps to it. Either of these works:
     - Rom Patcher JS (in your browser): https://www.marcrobledo.com/RomPatcher.js/
     - Floating IPS (Flips)
3. Play the patched ROM in mGBA or any GBA emulator.

Your Playtest 12 save should keep working: give the new ROM the same
file name as before (so the save file matches) or copy the .sav across.
Use an in-game save, not a save state from an older playtest.


NEW SINCE PLAYTEST 12
---------------------
Solar Blade
- Solar Blade now hits on the turn you use it, with no charging
  turn and no need for sun. Its power went from 125 to 95.
- Lurantis learns it when it evolves. Ceruledge has it as a Lv 1
  move: teach it with RELEARN in the party menu.


PLEASE TRY
----------
- Use Solar Blade with Ceruledge or Lurantis. It should hit right
  away with the slash animation (no "took in sunlight" message).
- Check its power shows 95 on the summary screen.
- Is Ceruledge too strong or too weak with it now?
- Everything from Playtest 12 still needs eyes: the Farfallarbor
  armors, Roxanne's Shieldon, signature moves on evolution, and the
  Bird Keepers and Fortellini Gym.


DEBUG MENU
----------
This build has the developer's debug menus turned on, so you can
skip ahead or set up a test:
  - Overworld: hold R and press START (mGBA keyboard: hold S, Enter)
  - In battle: press SELECT on the battle menu (mGBA: Backspace)
  - Sprite viewer: SELECT on a summary screen (mGBA: Backspace)
Use a separate save or a save state first, and say in your report
if that save used the debug menu.


AFTER-BATTLE GLITCHES
---------------------
If anything odd happens right after a battle (the player moving on
their own, buttons not working, a freeze, strange graphics), make a
SAVE STATE right away (mGBA: File > Save State) and send it in.
