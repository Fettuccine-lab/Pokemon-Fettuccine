POKEMON FETTUCCINE VERSION - PLAYTEST 7
=======================================

Thanks for testing! This one is a small update: the modern Exp. Share,
a party menu shortcut, and a RANDOMIZER text fix.


HOW TO PLAY
-----------
1. You need a clean US Pokemon Emerald ROM (not included).
   It should match:
     CRC32: 1F1C08FB
     SHA-1: f3ae088181bf583e55daf962a92bb46f4f1d07b7
2. Apply fettuccine-playtest-7.bps to it. Either of these works:
     - Rom Patcher JS (in your browser): https://www.marcrobledo.com/RomPatcher.js/
     - Floating IPS (Flips)
3. Play the patched ROM in mGBA or any GBA emulator.

Your Playtest 6 save keeps working: give the new ROM the same file
name as before (so the save file matches) or copy the .sav across.
Use an in-game save, not a save state from an older playtest.


NEW SINCE PLAYTEST 6
--------------------
Exp. Share
- It's now a key item, in your bag from the start of a new game and
  already switched on. Your whole team gets 50% Exp. from each
  knockout, and also gains EVs. Pokemon that fought still get full
  Exp.
- Turn it on or off by using it from the Key Items pocket.
- On an older save, Nurse Joy gives it to you the next time you heal.
  If you already had the old Exp. Share, you keep that copy too.

Party menu
- Press SELECT on a Pokemon (mGBA: Backspace) to go straight to
  switching it with another party member.

Mr. Garlic
- MR. STONE is now MR. GARLIC, to match his company.
- He now gives you an AMULET COIN for delivering his letter to Sam.

Smaller changes
- PROF. ALAN now shows you a Hoothoot in the opening speech.
- Fixed the text overlapping after the RANDOMIZER question in a new
  game.
- The Linguicove Department Store lottery's 3-digit prize is now a
  Lucky Egg.


PLEASE TRY
----------
- Start a new game: watch the opening speech and answer the
  RANDOMIZER question, then check your Key Items for the Exp. Share.
- Win a battle with benched Pokemon, with the Exp. Share on and off.
- Press SELECT in the party menu: swap two Pokemon, cancel with B,
  and swap your lead Pokemon.
- Load an older save and heal at a Pokemon Center.
- Deliver the letter to Sam, then go back to MR. GARLIC for the
  AMULET COIN. Win a trainer battle with it held to check you get
  double the money.


DEBUG MENU
----------
This build has the developer's debug menus turned on, so you can
skip ahead or set up a test:
  - Overworld: hold R and press START (mGBA keyboard: hold S, Enter)
  - In battle: press SELECT on the battle menu (mGBA: Backspace)
  - Sprite viewer: SELECT on a summary screen (mGBA: Backspace)
Use a separate save or a save state first, and say in your report
if that save used the debug menu.


AFTER-BATTLE GLITCHES
---------------------
If anything odd happens right after a battle (the player moving on
their own, buttons not working, a freeze, strange graphics), make a
SAVE STATE right away (mGBA: File > Save State) and send it in.


KNOWN PLACEHOLDERS
------------------
- Brian, Prof. Alan, Sam, Mike, Joe Q, WILDCARD, JASON and BLOBBY
  still use old Emerald sprites. Prof. Alan's battle sprite is a
  Gentleman.
- Retro Salvage Games shops still have blue roofs and MART signs.
- A few map graphics still say HOENN.
- Sam's shiny Metagross isn't cheddar-yellow yet.


PLEASE REPORT
-------------
- Crashes or freezes, especially right after gaining Exp. in battle
- Exp. going to the wrong Pokemon, or the wrong amount
- Text that runs off the box
- Anything that blocks progress
- Battles that feel too hard or too easy now the whole team gains
  Exp.
- Say whether your save is a RANDOMIZER game

If you can, say where you were and what you were doing, and send a
screenshot or your save file.
