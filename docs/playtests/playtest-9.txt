POKEMON FETTUCCINE VERSION - PLAYTEST 9
=======================================

Thanks for testing! This one fixes a big party bug, removes friendship
evolutions, brings back Hail, and gives Brian a new grudge: sauce.


HOW TO PLAY
-----------
1. You need a clean US Pokemon Emerald ROM (not included).
   It should match:
     CRC32: 1F1C08FB
     SHA-1: f3ae088181bf583e55daf962a92bb46f4f1d07b7
2. Apply fettuccine-playtest-9.bps to it. Either of these works:
     - Rom Patcher JS (in your browser): https://www.marcrobledo.com/RomPatcher.js/
     - Floating IPS (Flips)
3. Play the patched ROM in mGBA or any GBA emulator.

Your Playtest 8 save should keep working: give the new ROM the same
file name as before (so the save file matches) or copy the .sav across.
Use an in-game save, not a save state from an older playtest.


NEW SINCE PLAYTEST 8
--------------------
Bug fix: catching with a full party
- Catching a Pokemon with a full party no longer asks if you want to
  add it to your party. That option could copy your first Pokemon
  over your whole party. New catches now go straight to the PC, like
  in the original Emerald. Use the Pkmn Box Link to swap them in.

No more friendship evolutions
- Every Pokemon that used to evolve by friendship now evolves by
  level, at any time of day:
    Lv 12: Pichu, Cleffa, Igglybuff, Azurill, Happiny
    Lv 15: Togepi, Budew
    Lv 20: Chingling
    Lv 25: Riolu
    Lv 28: Alolan Meowth
    Lv 30: Munchlax, Buneary, Woobat, Swadloon, Snom
    Lv 35: Golbat
    Lv 40: Chansey
- Happiny no longer needs an Oval Stone.
- Eevee uses stones instead: Sun Stone for Espeon, Moon Stone for
  Umbreon, Shiny Stone for Sylveon (all sold at the evolution counter
  on the Linguicove Dept. Store's 3rd floor).
- A Pokemon from an old save that is already past its new level
  evolves the next time it levels up.

Hail is back
- Snow Warning (Snover, Abomasnow, Alolan Ninetales) now starts Hail
  instead of Snow. Hail hurts every Pokemon that isn't Ice type at
  the end of each turn.

Pokedex area map
- The area page now shows everywhere a Pokemon lives at any time of
  day, and no longer has the morning/day/evening/night switcher. (It
  used to look empty outside the morning.)

Brian
- Brian's big hate is now SAUCE, and he's sure all sauce is just jar
  sauce. Lots of his lines changed, plus a few from people who talk
  about him.
- His PokeNav title has changed too.


PLEASE TRY
----------
- Catch a Pokemon with a full party. It should go straight to the PC,
  and your party should stay exactly as it was.
- Evolve some of the Pokemon above, at different times of day, and
  try the three stones on Eevee. Check the Pokedex shows the new way
  each one evolves.
- Fight Brian's Snover (Route 110 onward). Your Pokemon should take
  Hail damage each turn.
- Open the Pokedex area page for a few Pokemon at night.
- Read Brian's scenes and PokeNav calls. Look for text that runs off
  the box or breaks in an odd place.


DEBUG MENU
----------
This build has the developer's debug menus turned on, so you can
skip ahead or set up a test:
  - Overworld: hold R and press START (mGBA keyboard: hold S, Enter)
  - In battle: press SELECT on the battle menu (mGBA: Backspace)
  - Sprite viewer: SELECT on a summary screen (mGBA: Backspace)
Use a separate save or a save state first, and say in your report
if that save used the debug menu.


AFTER-BATTLE GLITCHES
---------------------
If anything odd happens right after a battle (the player moving on
their own, buttons not working, a freeze, strange graphics), make a
SAVE STATE right away (mGBA: File > Save State) and send it in.


KNOWN PLACEHOLDERS
------------------
- Brian, Prof. Alan, Sam, Mike, Joe Q, WILDCARD, JASON and BLOBBY
  still use old Emerald sprites. Prof. Alan's battle sprite is a
  Gentleman.
- Retro Salvage Games shops still have blue roofs and MART signs.
- A few map graphics still say HOENN.
